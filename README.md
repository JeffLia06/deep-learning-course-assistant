# Deep Learning Course Assistant

A classification-guided question answering system for deep learning concepts.

## Architecture

Question
→ DistilBERT Classifier
→ Predicted Category
→ FLAN-T5 Generator
→ Answer

## Project Status

Under active development.

This repository is a ground-up redesign of an earlier prototype with a focus on:

- modular ML architecture
- reproducible experiments
- efficient fine-tuning
- systematic evaluation
- deployment-ready inference
